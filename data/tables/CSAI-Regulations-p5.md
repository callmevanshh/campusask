# 3. Requirements for Graduation

* For 2025 batch onwards

For a B.Tech. (CSAI) degree, a student must satisfy all the following requirements:

1. Earn a total of 156 credits, inclusive of 2 credits each from Self-Growth(SG) and Community Work (CW)(equivalent to 39 full courses of 4 credits).
2. Successfully complete all the core courses.
3. CSE Systems Bucket: Successfully complete at least one course from this bucket comprising of the following courses:
    * CSE202 Fundamentals of Database Management Systems
    * CSE232 Computer Networks
    * CSE511/ECE511 Computer Architecture
4. AI Bucket: Successfully complete any six courses (24 Credits of coursework) from the AI Bucket
    * IP/IS/BTP/OC, etc. are excluded.
    * A student must register with the AI course code to avail AI bucket credits. For dual code courses, a student must register the course with the AI course code to avail AI bucket credits.
    * The current list of courses is available at LINK
5. SSH Bucket: Successfully complete 12 credits of the SSH bucket. This bucket comprises any SSH course (with course code SOC, PSY, ECO, SSH) with 1xx, 2xx, or 3xx course code, including those in the Ethics and Philosophy Bucket. The ENT courses are not part of this further, at least 4 credits of these should be from the Ethics and Philosophy bucket given above.
